# QQ 官方机器人框架 2.0

> ⚠️ **半成品状态** — 本项目已无后续开发计划，源码仅供参考学习。

基于 PHP + SQLite 的 QQ 官方机器人多用户管理平台，支持一个站点同时托管多个 QQ 机器人的回调服务。

## 功能

- **多用户系统** — 注册/登录，管理员可管理所有用户
- **机器人管理** — 添加/删除机器人，自动获取机器人名称和头像
- **回调服务** — 统一的 Webhook 入口，分发到各机器人的插件目录
- **会员体系** — 卡密充值余额，余额购买机器人使用权（按月计费）
- **插件系统** — 在线编辑插件代码，支持启用/禁用，插件热加载
- **后台管理** — 用户管理、卡密管理、定价设置、系统配置
- **白色主题 UI** — 响应式设计，支持移动端访问

## 技术栈

- **后端**: PHP 7.4+（纯原生，无框架依赖）
- **数据库**: SQLite3
- **前端**: HTML + CSS + Vanilla JavaScript
- **CDN**: BootCDN（国内加速）

## 使用

1. 将源码部署到支持 PHP 的 Web 服务器
2. 确保 `data/` 目录可写（SQLite 数据库自动创建）
3. 访问站点，首次运行自动创建默认管理员账号
4. 默认管理员：`admin` / `admin123`（登录后请立即修改密码）

## 注意事项

- 需要 PHP 7.4+ 且启用 SQLite3 扩展
- `data/` 目录需要 Web 服务器写入权限
- 本项目为半成品，仅供学习参考
